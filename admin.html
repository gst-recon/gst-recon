Firestore setup (ek baar, 2 minute)

Site Control ke liye Firebase me Firestore database chahiye:

  1. Firebase console kholo → project gst-recon-ee386 → Build → Firestore Database → Create database → Start in production mode → location asia-south1 (Mumbai) → Enable.
  2. Rules tab me ye rules daal ke Publish dabao (read sabke liye, write sirf tumhare liye):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /config/site {
      allow read: if true;
      allow write: if request.auth != null
        && request.auth.token.email == "prathameshrampure78@gmail.com";
    }
  }
}
